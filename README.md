# growth-radar

哪些账号突然长起来了，什么作品值得拆，评论里的人又在为什么买账？growth-radar 是一套跨平台内容研究机制：从涨粉榜和连续观测里找候选，结合公开作品、评论和事件线索，筛掉明显受入驻、回归、活动等因素影响的案例，再把值得看的内容往下拆。榜单是找线索的起点，研究最后要落到具体作品上。

## 可以拿它研究什么

- **找近期值得看的作者和作品**：“看看这周谁涨得快，挑几组有具体作品可研究的案例。”把热闹的榜单缩成能继续深挖的候选。
- **拆解内容为什么吸引人**：“这几个账号最近的作品，有哪些表达和制作方法值得学？”结合作品技巧、评论反馈和当时的社会背景展开。
- **核查一个突然爆发的账号**：“这个账号一下涨了很多，是作品带动，还是入驻、回归或活动？”查公开时间线，把支持不同解释的证据列出来。
- **比较平台间的内容线索**：“B站、抖音、小红书最近有哪些相似题材？讨论的重点一样吗？”按各平台可取得的样本比较，保留来源和缺失项。

每个案例分开记录归因可信度与异常状态，让你知道哪里有证据、哪里还只是值得继续查的线索。

## 核心机制

**三道门。** 先查刷粉与异常，再排除入驻、迁移、回归、活动等已知非作品因素，最后允许模型基于证据识别未预先枚举的其他非作品原因。它的重点是尽早停止错误案例，而不是把每个上榜账号都写成故事。

**两轴标签。** 每个案例同时记录归因可信度与异常状态。二者彼此独立：证据不足不等于异常，增长可疑也不等于已经证明刷粉。

**两段式深挖。** A 段只做账号锚定和作品驱动速判，筛除即停；B 段只拆解存活案例，分别分析作品技巧和社会环境背景。这能把调查预算集中到真正可能有学习价值的案例。

**观测契约。** 每个粉丝观测点记录是否精确、显示分辨率、供应商时间和是否低于分辨率。只有同源、同口径且供应商时间推进的观测才计算 delta；v2 schema 缺字段直接报错。

**completeness。** 报告不是简单的成功/失败，而是 `complete`、`partial`、`rank_only`、`failed` 四态。数据源降级、分析链中断和全源失败会落到不同状态，避免残缺结果伪装成完整报告。

## 数据源与公开边界

| 平台 | 公开组件 | 访问方式 | 是否需账户 | 数值性质 | 失败后 |
|---|---|---|---|---|---|
| B站 | 榜单文章、作品元数据、公开评论、字幕 | 公开接口与真实浏览器 | 通常不需要 | 平台公开值与第三方榜单并存 | 标主板块缺失；五板块全失败才 `failed` |
| 抖音 | 第三方日涨粉榜、公开作品线索 | 商业数据平台人工可见页、公开报道 | 依服务而异 | 第三方估算 | `partial`，分析链不能完成则 `rank_only` |
| 小红书 | 第三方日涨粉榜、公开作品线索 | 商业数据平台人工可见页、公开搜索 | 依服务而异 | 第三方估算 | `partial`，账号不唯一则停止深挖 |
| YouTube | 公开周榜、频道统计页、transcript | 公开网页 | 通常不需要 | 第三方统计或约数 | 无可比观测就不计 delta |
| X | 公开账号页与传播线索 | 真实浏览器 | 部分页面可能需要 | 常为约数 | 只留线索，不计精确 delta |

蝉妈妈、千瓜等商业数据平台有各自服务条款，其数值是第三方估算。本仓库不包含自动化批量抓取或访问限制规避方案，也不再分发受限数据；运行产物和真实账号案例不在仓库中。更细的接入与验收条件见 [PLAYBOOK.md](./PLAYBOOK.md)。

## 未包含的部分

- **交付层**：报告可以写本地文件、对象存储、数据库或任意文档系统。`state.sh` 接受 http(s) URL 或本地绝对路径作为最终 artifact。
- **通知层**：`check.py` 默认把提示打印到 stdout；设置 `GR_NOTIFY_CMD` 后，会将提示文本通过 stdin 交给你的命令。
- **调度层**：仓库不绑定 cron、systemd 或其他调度器。调度器只需启动工作流，并在合适时间运行 `check.py`。

## 运行环境与依赖

- Bash
- jq
- Python 3

目前仅在 macOS 实测；Linux 未验证。`state.sh` 的锁时间同时兼容 GNU 与 BSD `stat`，但这不等同于完整 Linux 兼容性承诺。

## 成熟度披露

截至首发，这套机制仅运行 3 轮（2 次人工、1 次定时 shadow），正式日更尚未启用。单日样本对长期情绪或热点的外推能力弱，归因也只依赖公开信号，没有创作者后台的一手数据。

数据源路径很容易变化：早期实测已出现浏览器对特定域名的访问条件变化，以及商业榜单免登录可见条数与旧记录不一致。这里的路径是带日期的参考快照，不是稳定接口承诺。

## 快速开始

运行隔离测试：

```bash
bash tests/run-tests.sh
```

阅读 [SKILL.md](./SKILL.md) 了解完整运行契约、筛选方法、报告结构和状态机；阅读 [PLAYBOOK.md](./PLAYBOOK.md) 了解五平台接入与降级。

可选配置：

```bash
cp local-config.example.sh local-config.sh
. ./local-config.sh
./state.sh start
```

本仓库是代码与机制参考；作者本机另有同名数据工作区，其中的报告、观测和真实案例不在本仓内。
